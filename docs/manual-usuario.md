# 1. O que é este sistema

O sistema centraliza o monitoramento de temperatura e umidade dos setores da fábrica.  
Ele mostra sensores em tempo real, gera alertas automáticos e permite consultar histórico para auditorias e análises.

---

# 2. Como acessar o sistema

1. Abra o navegador (Chrome, Edge ou Firefox).  
2. Digite o endereço: http://localhost:5173/
3. Aguarde o carregamento do dashboard.  
4. Caso necessário, faça login com suas credenciais.

---

# 3. Tela inicial – Dashboard

A tela principal exibe:

- Sensores Ativos  
- Sensores em Alerta  
- Sensores Offline  
- Última atualização  

Cada cartão de sensor mostra:

- Nome do setor  
- Temperatura atual  
- Status (Normal / Alerta / Offline)  
- Horário da última leitura  

**Cores do sistema:**

- 🔵 Azul → Normal  
- 🟠 Laranja → Alerta  
- 🔴 Vermelho → Offline  

---

# 4. Visualizar sensores

1. Acesse o menu lateral.  
2. Clique em **Dashboard**.  
3. Veja cada cartão de sensor com:
   - Temperatura
   - Status
   - Última leitura

Se um sensor estiver em alerta, ele aparecerá destacado.

---

# 5. Ver alertas

1. Clique em **Alertas** no menu lateral.  
2. A lista exibirá:
   - Data e hora  
   - Sensor afetado  
   - Valor registrado  
   - Limite permitido  
   - Status do alerta  

Use essa tela para identificar rapidamente problemas ambientais.

---

# 6. Consultar histórico

1. Clique em **Histórico**.  
2. Escolha:
   - Setor  
   - Tipo de métrica (temperatura/umidade)  
   - Intervalo de datas  
3. Clique em **Gerar Gráfico**.

Você pode:

- Ver tendências  
- Baixar CSV  
- Comparar setores  

---

# 7. Administração (somente autorizados)

Usuários com permissão podem:

### Gerenciar sensores
- Adicionar  
- Editar  
- Desativar  

### Gerenciar limites
- Temperatura máxima  
- Umidade máxima  
- Histerese  

### Gerenciar usuários
- Criar contas  
- Alterar permissões  
- Resetar senhas  

---

# 8. Dúvidas frequentes

**O dashboard não atualiza.**  
Verifique sua conexão ou recarregue a página.

**Não recebo alertas por e-mail.**  
Confirme seu cadastro com a TI.

**Um sensor aparece offline.**  
Pode ser falha SNMP. Informe o suporte.
